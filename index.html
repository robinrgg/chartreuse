        Couleurs des cuvées

        Toucher une pastille pour changer la teinte d'une cuvée. Le changement vaut pour tous vos appareils. La place de la cuvée dans le spectre ne bouge pas.

        Dépôt

        Enregistrement

        Chaque modification part dans cave.json sur GitHub, quelques secondes après la saisie. Tous vos appareils lisent ce même fichier.

        Réglages du dépôt et jeton d'accès

        Le jeton reste sur cet appareil, dans le stockage du navigateur — il n'est jamais écrit dans le dépôt. Sans jeton, l'appli reste consultable mais ne peut plus enregistrer. Créez-en un dans GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens, limité à ce seul dépôt, avec la permission Contents : Read and write.

        Sauvegarde hors ligne

        Utile pour archiver la cave ou la reprendre sans jeton.
